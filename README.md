## 丨命令列表

<details><summary>绑定登录</summary>

| 命令 | 说明 |
|------|:------:|
| `kq绑定 1234567` | 绑定卡拉彼丘(国服)账号 |
| `kq解绑 1234567` | 解绑卡拉彼丘(国服)账号 |
| `kq查看` | 查看当前已绑定的卡拉彼丘(国服)账号 |
| `kq切换 1234567` | 在已绑定账号间切换，不传默认切换下一个 |
| `kq战绩总览` | 查看当前账号的生涯总览卡片 |
| `kq战绩总览 1234567` | 查看指定 UID 的生涯总览卡片 |

</details>
